# Shubham Paithane | Portfolio

Personal portfolio site built with plain HTML, CSS and JavaScript, using Three.js and GSAP for the interactive visuals.

**Live:** https://my-portfolio-oerl.vercel.app

## Structure

- `index.html`: the whole site (markup, styles and scripts)
- `public/resume.pdf`: resume linked from the site

## Run locally

```bash
npm install
npm run dev
```

Or just open `index.html` in a browser.

## Build

```bash
npm run build
```

Output goes to `dist/`, which is what Vercel deploys.
